Browser SPARC

A SPARCstation 5 emulated in this page: QEMU built for WebAssembly with its TCG interpreter, OpenBIOS as the firmware, and wisp, a one-program Linux, with its shell on the serial console. wisp's other machines run the same way: pick one below. Nothing leaves the browser. How it works.

SPARCstation 5 (sparc32) Sun Ultra (sparc64) PC (x86_64) Arm virt (aarch64)

Starting... Boot from the firmware instead (minutes)

Try help, info, bench, mandel and banner; poweroff stops the machine. The emulated CPU runs in QEMU's interpreter compiled to WebAssembly, roughly 100 times slower than QEMU on a PC, so bench takes about 40 seconds on each of the machines.
