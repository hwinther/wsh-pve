Browser SPARC

A SPARCstation 5 emulated in this page: QEMU built for WebAssembly with its TCG interpreter, OpenBIOS as the firmware, and wisp, a one-program Linux, with its shell on the serial console. Nothing leaves the browser. How it works.

Starting... Boot from OpenBIOS instead (a few minutes)

Try help, info, bench, mandel and banner; poweroff stops the machine. The emulated CPU runs in QEMU's interpreter compiled to WebAssembly, roughly 100 times slower than QEMU on a PC, so bench takes about half a minute.
