The [sparc lab](https://github.com/hwinther/wsh-pve/tree/main/e2e/sparc) records every run it makes:
the serial console as an [asciinema](https://asciinema.org) recording and, when the guest has a
framebuffer, a short time-lapse video of it. These few are from the lab's own runs against the
packaged QEMU; the weekly lab run keeps the recordings of every case in its workflow artifact.

The recordings are documentary: short, time-compressed, from the lab's unattended runs. Pauses
longer than a second are cut (and the install plays three times as fast); the marks on the progress
bar are the lab's steps (hover for the title, or use `[` and `]` to jump between them). Space pauses,
the arrow keys seek.

## Solaris 2.6 text install on SS-5

The End User install from the Solaris 2.6 (5/98) CD on the serial console, as
`solaris-install-serial.py` drives it (language, terminal type, system identification, software
group, disk, then the installation itself and `halt`). SS-5, OpenBIOS, 256 MB.

## Recording your own

Every `lab.py run` writes `serial.cast` (and `serial.fast.cast`, the pauses cut) next to its other
evidence, and `fb.webm` when the machine has a framebuffer; the run's `index.html` plays both offline.
`asciinema play serial.cast` plays a cast in a terminal. The lab's
[README](https://github.com/hwinther/wsh-pve/tree/main/e2e/sparc#recordings) has the details, and how
a recording gets onto this page.
